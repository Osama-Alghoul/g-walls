Place Vendôme Mall – EIFS Decorative Systems

Project Overview

Place Vendôme is a large-scale commercial development located in Lusail City, Qatar. GWALLS contributed to this landmark project through the supply and application of advanced EIFS decorative cladding and architectural elements, delivering both aesthetic refinement and long-term façade performance.

Doha, Qatar

System Application

GWALL's EIFS decorative systems were utilized extensively across the external facades of the mall, combining thermal insulation with architectural detailing. The system allowed for the creation of complex design features while maintaining consistent insulation performance across large surface areas.

Applications included:

  • EIFS external wall cladding
  • EPS-based decorative profiles and architectural details
  • Integrated insulation and finishing layers

Technical Highlights

  • Lightweight EIFS system reducing structural load
  • High thermal performance suitable for hot climates
  • Precision-manufactured EPS decorative elements
  • Compatibility with large-scale commercial facades
  • Smooth integration with architectural design requirements

Performance Benefits

What does the building gain by using this system:

  • Thermal Efficiency: Improved building envelope performance and reduced heat gain
  • Design Flexibility: Ability to execute complex façade geometries and detailing
  • Durability: Weather-resistant exterior finishes
  • Construction Efficiency: Faster installation compared to traditional façade systems

Project Context

Located in Lusail City, Place Vendôme Mall required a façade system capable of meeting demanding architectural standards while addressing the region's climatic conditions. The use of EIFS decoration provided an optimal balance between design expression, insulation performance, and construction efficiency for a high-traffic commercial environment.

Project Summary

The Place Vendôme project demonstrates the successful implementation of GWALLS EIFS decorative systems in a large-scale commercial development. The project highlights GWALLS' capability to support complex architectural designs while delivering high-performance exterior solutions suitable for the Middle East.

Project Information

  • Project Name: Place Vendôme Mall
  • Location: Lusail City, Qatar
  • System Used: EIFS & EPS
  • Scope: Exterior façade cladding
  • Total Area: 75,000 sqm
